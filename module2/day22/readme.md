# Birr Watch 🇪TH

Birr Watch is a live Ethiopian Birr (ETB) exchange-rate tracker and converter built with JavaScript, HTML5, and CSS3. It fetches real-time rates from an external exchange rate API and saves your selected currency conversions and watchlist items locally in your browser.

## Features

- **Live Exchange Rates**: Fetches real-time exchange rates relative to ETB.
- **Currency Converter**: Instant conversion calculations for selected target currencies.
- **Watchlist**: Track exchange rates for multiple currencies simultaneously.
- **Persistence**: Persists selected options and watchlist data using `localStorage`.
- **Dynamic UI**: UI updates dynamically driven by state updates.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+, Async/Await, Fetch API, LocalStorage)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` directly in your browser or run it using a local development server (such as Live Server in VS Code).
